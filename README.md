# 명찰 만들기

브라우저에서 엑셀 명단을 읽어 행사 인쇄물을 준비하는 도구입니다. 하나의 명단으로 세 가지 출력물을 만들 수 있습니다. 명단은 서버로 전송하거나 저장하지 않으며, 열려 있는 브라우저 안에서만 처리합니다.

## 출력 형식

명단을 불러온 뒤 왼쪽 **출력 형식**에서 인쇄물을 고를 수 있습니다. 세 형식 모두 같은 명단을 사용합니다.

- **목걸이 명찰**: 세로형 95 × 123 mm 명찰. A4 세로 한 장에 4개.
- **삼각 명패**: A4 가로 한 장에 1명. 점선 두 곳을 따라 3등분으로 접으면 삼각기둥으로 서는 탁상 명패입니다. 앞·뒤 두 면에 이름이 인쇄되며(위쪽 면은 180° 뒤집혀 있어 접으면 양쪽에서 바로 읽힘), 나머지 한 면은 바닥이 됩니다. 인쇄 시 프린터 용지 방향을 **가로(landscape)**로 설정하세요.
- **참석자 서명부**: 번호·소속·이름·서명란 표. A4 세로로 인쇄되며, 여러 장이 되면 머리글이 매 장에 반복됩니다.

인쇄 시 프린터 용지 방향은 각 형식 안내(왼쪽 **인쇄 준비**)를 따르세요. 삼각 명패는 **A4 가로**, 나머지는 **A4 세로**입니다.

## 로컬 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev
```

개발 서버 주소를 브라우저에서 열면 됩니다. 배포용 결과는 `npm run build`로 만들 수 있습니다.

## 엑셀 명단 준비

업로드 창에서 명찰 형식을 먼저 고르고 **엑셀 양식 다운로드**를 누르면 바로 사용할 수 있는 `.xlsx` 양식을 받을 수 있습니다.

- **이름만**: `이름` 열이 필요합니다.
- **소속 + 이름**: `소속`, `이름` 열이 필요합니다. (예전 `기관` 머리글도 자동으로 인식합니다.)

열 이름이 다르거나 머리글이 첫 줄에 없다면, 파일을 고른 뒤 워크시트·머리글 행·각 열을 직접 선택할 수 있습니다. 소속과 이름에는 서로 다른 열을 지정해야 합니다.

## 업로드 규칙과 제한

- `.xlsx`, `.xls` 파일만 지원합니다.
- 파일은 10 MiB 이하, 명단은 1,000명 이하입니다.
- 빈 행은 건너뛰지만, 선택한 이름 또는 소속 열에 값이 비어 있는 행은 가져오지 못합니다.
- 선택한 열의 수식이나 엑셀 오류 셀은 값으로 붙여넣어야 합니다.
- 숨긴 행도 워크시트 범위 안에 있으면 명단에 포함됩니다. 제외할 사람은 행을 삭제하거나 별도 시트를 사용하세요.
- 암호화되었거나 손상된 파일, 지나치게 큰 시트는 읽을 수 없습니다.

명단을 불러오기 전에 오류가 발견되면 기존 명단은 그대로 유지됩니다. 파일 선택을 취소하거나 업로드 창을 닫아도 기존 명단은 바뀌지 않습니다.

## 인쇄

인쇄 화면에서는 A4 세로 용지에 한 장당 네 개의 95 × 123 mm 명찰을 배치합니다. 브라우저 인쇄 창에서 다음을 설정하세요.

- 용지: **A4, 세로**
- 배율: **실제 크기 100%**
- 머리글과 바닥글: **끔**

프린터의 여백 보정이나 자동 맞춤 기능은 출력 크기를 바꿀 수 있으므로 끄는 편이 좋습니다.

## 개인정보와 한계

파일을 처리하는 데 인터넷 연결이나 계정이 필요하지 않습니다. 새로고침하거나 탭을 닫으면 현재 불러온 명단은 사라집니다. 이 도구는 엑셀 파일의 이름과 소속 텍스트만 사용하며, 파일을 저장하거나 다른 사람과 공유하지 않습니다.
